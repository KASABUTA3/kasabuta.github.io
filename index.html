公開ギャラリー運用ガイド

「更新しやすい」「見つけやすい」「共有しやすい」を重視した公開設計です。作品追加の流れをここにまとめています。

1. 作品情報を整理

タイトル・概要・タグ・公開リンクを準備しておくと、一覧の質が安定します。

2. JSの配列を更新

assets/js/main.js の作品データに追加するだけでギャラリーへ反映されます。

3. GitHub Pagesで公開

Settings → Pages で main ブランチの /(root) を指定し、公開URLを共有してください。

Guide

公開ギャラリーの使い方

一般公開向けに作品情報を整理しています。SNS や配布ページに飛べるリンクをまとめることで、初めての方でも迷わずたどり着けます。

URL ひとつで共有

GitHub Pages の公開URLにまとめているので、リンクを送るだけで誰でも閲覧できます。

タグ検索で発見

ジャンル別のタグと検索で、見たい作品だけを素早く探せます。

リンク先を更新

配布ページや動画URLを差し替えるだけで、最新の公開先へ誘導できます。
